# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

	-リモートリポジトリとは、GitHubといったコードを共有している保管場所
	-ローカルリポジトリとは、自身のPCにある保管場所

## プッシュとマージの違いは何でしょうか？

	-プッシュはローカルのコミットをリモートへ送ること
	-マージはあるブランチの変更を別ブランチへ統合すること

## コミットとプッシュの違い

	-コミットは変更内容を記録すること
	-プッシュはコミットした内容をリモートに送信すること

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

	-何をしたのかを簡潔に書く

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

	-ローカルからマージは、自分のPC上でブランチを統合してからGitHubに送信する
	-プルリクエストは、他の開発者にコードを確認してもらい、問題がないことを確認してからmainに取り込める

## コンフリクトを起こしてしまった場合、どう対処すべきですか？
	
	-コンフリクトが発生したファイルを探す。
	-残すべき内容を精査
	-コンフリクトの記号を残さない(>>>>>>>,=======,<<<<<<<)
	-ステージング,コミット,プッシュをする
